# Raw Dataset

This folder is intended to store the original, unmodified dataset used for the Food Delivery Operations analysis.

## Dataset Source
The dataset was provided in the Kagnus internship project brief.

[Download Dataset](https://drive.google.com/file/d/1O9WYS92iJPZoC6skyYlpcdP8Kre7eW6z/view?usp=sharing)

## Dataset Details
- **Dataset name:** Food Delivery Operations
- **Original records:** 45,584
- **Columns:** 20
- **Format:** CSV

## Important Note
The original dataset is kept unchanged to preserve the source data. All data cleaning and preprocessing are performed on a separate copy, which is saved in the `data/processed/` folder as `cleaned_food_delivery.csv`.
