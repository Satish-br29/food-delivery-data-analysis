# Food Delivery Data Analysis

## Project Overview
This project focuses on understanding and cleaning a food delivery dataset
as part of the Kagnus Data Analytics Virtual Internship - Week 1.

## Objective
- Understand the dataset structure and columns.
- Identify missing values and duplicate records.
- Inspect categorical and numerical data.
- Validate date and time columns.
- Clean the dataset and document the cleaning process.

## Dataset Information
- Original records: 45,584
- Columns: 20
- Domain: Food Delivery

## Tools Used
- Python
- Pandas
- NumPy
- Google Colab

## Project Structure
- data/raw/ - Information about the original dataset.
- data/processed/ - Cleaned dataset.
- notebooks/ - Data understanding and cleaning notebook.
- docs/ - Cleaning log.

## How to Run
1. Clone this repository.
2. Install dependencies using pip install -r requirements.txt.
3. Open the notebook in Google Colab or Jupyter Notebook.
4. Upload the original dataset to the notebook environment.
5. Update the CSV path if necessary and run the notebook cells in order.

## Week 1 Observations
- The dataset contains 45,584 records and 20 columns.
- Missing values were found in 9 columns.
- No completely duplicated rows or duplicate order IDs were found.
- Categorical and numerical columns were inspected.
- A separate cleaned dataset and cleaning log were created.
